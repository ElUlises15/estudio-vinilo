# Estudio Vinilo — dirección de diseño

Público: bandas locales que quieren ensayar juntas o registrar una toma. Acción principal: abrir una consulta de WhatsApp al número del brief. Almagro es la ubicación conceptual; no se inventa dirección ni horario.

Paleta: midnight #0D0D12 para fondo, cream #F0E6D2 para lectura, amber #E8A54B para acción, oxblood #6B1E2F para la etiqueta del disco; gris #B1AC9F para texto secundario.

Tipografía: Barlow Condensed 600 para títulos con carácter de afiche musical; DM Sans para navegación y lectura. Fuentes Google con display swap y alternativas de sistema. Ancho máximo 1280px. Copy acotado, lectura entre 35 y 65 caracteres por línea.

Composición móvil: navegación siempre visible, título, copy/CTA, sala con vinilo superpuesto; secciones en columna, tarifas en dos columnas y CTA final. Escritorio: título y CTA asimétricos, foto y vinilo al lado, dos columnas fotográficas, tarifas como lista de sesiones. Gesto principal: disco CSS con giro de 32 segundos, control de pausa y reduced-motion. Sin audio automático.

Referencias de dirección (sin reutilizar assets ni código):
- A: https://electricladystudios.com/ — estudio como lugar físico y fotografía de música, composición editorial centrada en imágenes.
- B: https://www.abbeyroad.com/ — lenguaje de estudio y jerarquía de servicios; acá se adapta a una escala barrial, tonos tungsteno y títulos de afiche.
- C: https://www.discogs.com/ — concepto de catálogo y lados de un disco, navegación textual directa. Referencia conceptual: acceso web devolvió 403, no se afirma revisión visual del sitio actual.

No hay kit vertical para estudios musicales. No se aplica el de otro rubro. La decisión propia es la relación de sala fotografiada y disco en movimiento, con precios como lista de sesiones en vez de tarjetas. Datos comerciales y fotos están identificados como demo. No se publica.
